Lingutribe 使用手册

版本 v0.1.2（2026-08-15）· 面向使用者的操作说明

一、这是什么

Lingutribe 是一个装在你电脑上的英语学习工具。它把听、读、查词、记笔记、积累生词、AI 答疑放在同一个软件里，全程在本地运行，不依赖网络和账号。

想做的事用它怎么做
听懂英语音频 / 视频导入材料 → 自动转出字幕 → 边听边看，点词查义
读懂英语文章导入文章 → 点击生词查看释义 → 选中一段可复制 / 提问 / 朗读
查单词任何单词一点即出解释（离线词典，装过词典文件后无需联网）
记笔记边学边记，自动保存，随时回看
积累生词查过的词一键加入生词本，按词频上色方便复习
问 AI遇到不懂的句子，选中后让 AI 结合上下文讲解
关于隐私：你的音频、文章、笔记、生词都保存在自己电脑上，不会上传到任何地方。只有你主动配置云端 AI 时，相关内容才会发给对应服务商。

二、安装与启动

1. 安装

  1. 下载安装包：Lingutribe-0.1.2-arm64.dmg。
  2. 双击打开，把 Lingutribe 图标拖进"应用程序"文件夹。

2. 首次打开

  • 在"应用程序"里找到 Lingutribe，右键 → 打开；如果系统提示"无法验证开发者"，选仍然打开即可。
  • 之后应用会正常启动，出现主界面，无需安装任何其他软件。
提示：首次使用语音识别 / 朗读时，应用会自动下载所需模型（一次约几十到几百 MB），下载完成后即可完全离线使用。

三、界面一览

打开应用后，左侧是导航栏，点一下即可切换功能：

入口用途
音频导入并学习英语音频（播客、演讲等）
视频导入并学习英语视频
阅读导入并精读英语文章
生词查看和管理你收藏的生词
笔记查看和管理你的笔记
对话与 AI 自由聊天
设置外观、语言、语音识别、朗读、词典、AI 模型等

右侧是主要内容区；查词、AI 讲解会以面板形式出现在最右侧。

四、听音频 / 看视频

1. 导入材料

  • 本地文件：点"上传"，选择电脑上的音频或视频文件（单个最大 500MB）。
  • 网址：粘贴视频 / 播客链接，应用会自动下载。
  • 导入成功后，材料会出现在左侧列表中，点击即可打开。

2. 转字幕

  • 打开材料后，点工具栏的"转写"按钮，稍等片刻，字幕就会出现在下方。
  • 字幕按句自动分段，句子不会碎成零散片段。

3. 学习

  • 播放 / 暂停：按 空格。
  • 语速：工具栏可调 0.5× – 2×。
  • 点词跳转：点击字幕里的任意单词，播放会跳到那个位置，并弹出词典解释。
  • 波形图：拖动可定位；可缩放、可折叠。
边看边记：点播放器右上角的笔记本图标，内容下方会出现笔记框，输入的内容会自动保存（见"记笔记"）。

五、阅读文章

1. 导入文章

  • 本地文件：上传 .txt 或 .md 文本。
  • 网址：粘贴新闻 / 博客链接，应用会自动提取正文（去掉广告和杂项）。

2. 阅读与操作

  • 点单词查义：单击任意单词，右侧弹出词典解释。
  • 选中一段：浮出复制 / 问 AI / 朗读三个按钮——可复制、可让 AI 讲解这段、可只朗读这一小段。
  • 朗读全文：点顶部 Read aloud，应用朗读整篇文章，逐句高亮。

六、查单词

1. 基本用法

  • 在字幕或文章里单击任意单词，右侧即显示：音标、释义（按词性分组）、例句。
  • 如果词典里没有这个变形词（如 running），会自动尝试还原成原形（run）再查。

2. 安装词典（可选，但推荐）

  • 词典文件是 .mdx 格式（发音包是 .mdd），装好后查词完全离线。
  • 进入设置 → 词典，点 Reveal folder 直接打开词典目录，把 .mdx 文件放进去即可。
  • 放好后点 Test install，确认应用识别到了词典。

3. 多本词典怎么选

  • 装了多本词典时，到设置 → 词典下拉选择用哪本解读；选"自动"则由应用按顺序找第一个能查到的。
  • 查询结果下方会标注来自哪本词典。
没有本地词典也能用：查不到的词，应用会自动请 AI 给一个简洁的双语解释（需先配置 AI 模型）。

七、记笔记

1. 笔记页

  • 左侧点"笔记"：左边是笔记列表（按创建时间排列），右边是编辑区。
  • 点 + New 新建；顶部写标题，正文支持 Markdown 排版；点 Save 保存；列表项悬停可删除。

2. 边学边记（推荐）

  • 在音频 / 视频 / 阅读界面，点顶部笔记本图标，内容下方会出现一个笔记框。
  • 这个笔记自动关联当前材料：下次打开同一材料，笔记还在；输入停止约半秒后自动保存，无需手动操作。
  • 它也会同时出现在"笔记"页列表里。

八、生词本

  • 收藏生词：在词典面板点"+ Add to Words"，或到生词页手动添加。
  • 查看：左侧点"生词"，生词按卡片展示，颜色表示词频（见下）。
  • 筛选：可以搜索，或按词频颜色筛选。
  • 复习：点任意生词卡片，会再次打开词典解释。

词频颜色是什么意思

颜色含义
绿色最高频的词（前 1000），最常用
黄绿前 3000
蓝色前 5000
黄色前 6000
红色6000 以外（低频 / 生僻）

看文章时越偏红的词越值得记——它们是更高阶的词汇。

九、AI 助手

  • 结合上下文提问：阅读 / 看视频时，选中一句不懂的话，点Ask AI，AI 会结合整篇材料解释。
  • 自由聊天：左侧点"对话"，可与 AI 自由交流、练口语表达等。
  • 使用前提：AI 需要先配置一个模型（见"设置"）。默认使用本机 AI（需电脑上装好 Ollama）；也可以配置 DeepSeek、OpenAI 等在线模型。

十、设置

左侧点"设置"，按类别配置：

类别能做什么
系统界面外观（浅色 / 深色 / 跟随系统）、界面语言（中文 / English）、学习语言与母语
语音识别选择识别精度（模型越大越准、越慢），可提前部署模型
朗读选择音色（男声 / 女声）和朗读引擎（本地音色或在线音色）
词典检测已安装词典、一键打开词典目录、选择用哪本词典
AI 模型配置模型地址、模型名和密钥（本机 Ollama 或在线模型）

十一、常见问题

首次打开被系统拦截

  • 在"应用程序"里对 Lingutribe 右键 → 打开，然后点仍然打开即可。

词典查不到词

  • 确认 .mdx 文件放进了词典目录（设置 → 词典 → Reveal folder 可直接打开）；放好后点 Test install 确认识别。
  • 装了多本词典时，到设置 → 词典选择用哪本。

转字幕失败 / 朗读不出声

  • 先到设置 → 语音识别 / 朗读，确认模型已就绪（首次使用会自动下载；可点按钮提前部署）。

我的资料会丢吗

  • 所有数据（音频、文章、笔记、生词、设置）都存在你自己电脑上。卸载应用不会删除这些数据。

AI 不回答

  • 确认在设置 → AI 模型中配置了可用的模型：本机 AI 需先启动 Ollama；在线模型需填写正确的地址、模型名和密钥。
